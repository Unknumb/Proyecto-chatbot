# Proyecto Chatbot

Este proyecto implementa un chatbot interactivo que se ejecuta completamente en el navegador utilizando tecnologías modernas de frontend.

## Estructura del Proyecto

- `frontend/`: Contiene la interfaz de usuario del chatbot y toda la lógica de la aplicación

## Tecnologías Utilizadas

- WebGPU: Para aceleración por hardware y procesamiento eficiente del modelo
- ChatLLM: Integración de modelos de lenguaje para chat en el navegador
- Modelo de IA Gemma: Utilizamos el modelo Gemma 2b para procesamiento de lenguaje natural
- Web Workers: Para procesamiento en segundo plano sin bloquear la interfaz de usuario
- JavaScript/HTML/CSS: Para la interfaz de usuario y la lógica de la aplicación

## Requisitos

- Navegador moderno con soporte para WebGPU (Chrome recomendado)
- Conexión a Internet para la descarga inicial del modelo
- Tarjeta gráfica recomendada para mejor rendimiento

## Instalación

1. Clonar el repositorio
2. Abrir la aplicación siguiendo las instrucciones en `frontend/README.md`

## Ejecución

1. Abrir el archivo HTML en un navegador compatible
2. Esperar a que el modelo se cargue completamente
3. Comenzar a interactuar con el chatbot
